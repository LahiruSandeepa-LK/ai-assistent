# Mobile Statements — Feature Specification

## Goal
Let customers view and export up to 24 months of statements in the mobile app.

## Requirements
- PDF export generated on demand.
- Search statements by date range and amount.
- Accessibility: screen-reader friendly.

## Success Metrics
Statement load p95 < 2s; export success rate > 99.5%.
